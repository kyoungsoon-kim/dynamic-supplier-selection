# 🔬 정책 분석 (Plan B) — A/C/D는 쓸모없는가?

> 질문: 배포 모델이 B/E만 쓰고 A/C/D를 안 쓴다. A/C/D가 경제적으로 도태된 건가, 학습 실패인가?
> 결론: **학습 실패.** A/C/D는 쓸모 있고, 특히 **C가 단일 최강**인데 모델이 무시함.
> 작성: 2026-06-15

---

## 1. 단위당 조달비용 (정적, 주문=MOQ 기준)

`단위당 = P + ceil(MOQ/C_cap)*C_ship / MOQ`

| 업체 | tau(리드) | MOQ | 단위당 비용 |
| --- | --- | --- | --- |
| **A** | 7 | 1000 | **85.0** (최저) |
| B | 5 | 500 | 106.0 |
| C | 3 | 200 | 130.0 |
| E | 0 | 0 | 240.0 |
| D | 1 | 50 | 250.0 (최고) |

→ 단가만 보면 A가 압도적. 근데 이건 함정 (리드타임·재고동역학 무시).

## 2. 동역학 포함 시뮬 (업체별 최적 base-stock, 200일·8seed)

각 업체 단일 공급 + 최적 재주문점 S* 그리드서치 → 총비용:

| 업체 | 최저 총비용 | S* | 순위 |
| --- | --- | --- | --- |
| **C** | **8,931,628** | 2000 | 🥇 1위 |
| B | 9,830,791 | 2700 | 2위 |
| D | 10,388,885 | 1100 | 3위 |
| A | 12,514,099 | 2800 | 4위 |
| E | 13,467,018 | 600 | 5위 (최악) |

**반전**: 단가 최저였던 A가 동역학선 4위. 이유 = 리드 7일 + MOQ 1000 → S*가 CAP(2000) 넘는 2800 필요 → 보유·초과용량 페널티 폭발. 단가 우위를 재고비가 다 까먹음.
**C가 최강**: 리드 3 + MOQ 200(소량) → 반응성↑, 재고 적게 유지 가능.

## 3. 배포 모델의 실제 정책 비용

같은 시뮬에 모델(deterministic + MOQ보정) 투입:

| 항목 | 값 |
| --- | --- |
| 총비용 | **12,641,115** |
| 업체 사용 | B=950, E=594, None=56 / **A=C=D=0** |
| 단일 C 대비 | **1.42배 비쌈** |

→ 모델이 **최강 C를 버리고 최악 E를 비상용으로 씀**. 순진한 C 단일정책보다도 못함.

## 4. 결론

- **A/C/D 도태 아님.** 업체 5개는 lead/MOQ/단가 스펙트럼으로 잘 차별화됨 → **환경 파라미터 재설계 불필요.**
- B/E 붕괴는 **순수 학습 실패** (정책 collapse + 주문량 head 사망).
- README "BSP 대비 59%↓"는 휴리스틱 기준을 **최악 업체 A**로 잡은 비교 → 과장. 공정 비교(vs C)면 RL이 오히려 짐.

## 5. → Plan A (재학습) 처방

목표: C/D/A가 상황별로 선택되는 풍부한 정책.

1. **엔트로피 정규화** (coef 0.01~0.05) — 조기 붕괴 방지, 전 업체 탐색 보장
2. **주문량 head 부활** — 현재 raw 상수 3. advantage/보상 정규화, qty log_prob 가중치 점검
3. **베이스라인 비교 공정화** — greedy rollout baseline 유지하되 다업체 탐색 허용
4. **REINFORCE 트레이너 재작성** — repo에 학습루프 없음(모델정의+체크포인트만 잔존)
5. 검증 지표: 업체 사용 분포 + 총비용 < 8.93M(단일 C) 목표
